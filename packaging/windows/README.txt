Chiller Monitor is a desktop program. Open it from the Start menu or the desktop shortcut. It has its own window. Close that window to stop it.

Windows 11, and current Windows 10, include the Edge WebView2 Runtime this window uses. If the program says that runtime is missing, install it and start Chiller Monitor again.

Site profiles are stored in %LOCALAPPDATA%\ChillerMonitor and are kept if you uninstall.

Choose Demo chiller to try the HMI without a controller. Customise display, on the plant page, chooses what that site shows. To reach a real chiller, join the site network first, then enter the controller IP, port 502, and unit id.
