Chiller Monitor listens on this PC only, at http://127.0.0.1:8765.

The desktop and Start menu shortcuts open that page. Close the Chiller Monitor window to stop it.

Site profiles are stored in %LOCALAPPDATA%\ChillerMonitor and are kept if you uninstall.

Choose Demo chiller on the page to try the HMI without a controller. To reach a real chiller, join the site network first, then enter the controller IP, port 502, and unit id.
